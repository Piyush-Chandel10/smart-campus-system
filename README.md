# Smart Campus System

Arduino-based smart campus automation and safety system developed as a final year B.Tech project.

## Overview
The Smart Campus System combines multiple embedded modules designed to improve campus safety, automation, and energy efficiency using low-cost electronic components and sensor-based systems.

## Features
- LPG Leakage Detection System
- Fire Alarm System
- Automatic Night Light
- Touch Sensor Switch
- Smart Parking System

## Technologies & Components
- Arduino UNO
- MQ-2 Gas Sensor
- IR Sensors
- LDR
- BC547 Transistor
- Servo Motor
- Breadboard Prototyping

## Applications
- Smart campus automation
- Safety monitoring systems
- Energy-efficient lighting
- Smart parking management
- Embedded systems learning
